What is ROMpEIT?
================

What is ROM?
------------

Reduced Order Modelling (ROM) is a dimensionality reduction technique.

How does it apply to EIT?
-------------------------

Electrical Impedance Tomography (EIT) is a method to estimate the electrical conductivities of materials within a volume using electrides on its surface.
Parametric EIT, when applied to the human head, can be used to estimate the conductivities of the biological tissues that make it up, such as the scalp, skull, cerebrospinal fluid, brain, etc.
